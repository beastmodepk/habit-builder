# Changelog

## v0.1.0 — MVP (2026-10-23)

Native SwiftUI foundation, matching the design prototype's data model:

- Today screen with Today's Votes tally, Build and Quit sections
- Five seeded habits (10,000 steps, Workout, Healthy protein meal,
  Read 10 pages; quit: Alcohol outside cheat days)
- Habit detail: identity statement, habit stack, 2-minute version,
  Four Laws (build) / inverted laws, cost list, replacement habit (quit)
- Urge log and 10-minute urge timer
- On-device JSON persistence; add / edit / delete habits
- Stock SwiftUI UI — visual design port is the next milestone
  (see `docs/FEATURE-PLAN.md`)
